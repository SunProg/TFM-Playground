# Multi-regime v4 — consolidated tables

Companion to `multiregime_v4_results.md` (rev. 6, 2026-09-20). Conventions used in every table:

* **Cell format** `excess CE / accuracy gain` (synthetic bank) or `excess CE / accuracy gain / macro OvR AUC` (BeyondArena).
  excess CE = CE − class-prior CE (lower better, ≥ 0 = no better than the prior); accuracy gain = accuracy − majority-class
  accuracy (higher better); AUC = macro one-vs-rest (higher better). Ranks: mean rank over tasks, 1 = best.
* **Model names** `<family>-<size>`; families `original` (plain mix_scm prior), `r_z-fixed`, `r_z-curriculum`, `g_z-fixed`,
  `g_z-curriculum`; prefix `zx-` = trained with the regime score exposed (Exp 1); `mr-only` = multiregime-only prior (Exp 2).
  Sizes small (e64-l2), medium (e128-l4), large (e192-l6). All NanoTabPFN rows are **final checkpoints (step 10 000)** unless stated.
* **Synthetic bank panels** `mr1..mr4` = rule_mode multiregime with 1..4 regimes; `shared` = single shared rule; `all` = every cell.
  Pre-repair vs repaired bank: see results note header; differences ≤ 0.003.
* Published references: TabPFN v2.2 / v2.6 / v3, TabICL v1 / v1.1 / v2. Conventional ML baselines (BeyondArena only, default
  hyper-parameters, StandardScaler for logreg): `logreg` (C=1), `rf` (500 trees), `hgb` (sklearn HistGradientBoosting),
  `xgboost` (300 trees, lr 0.1, depth 6), `lightgbm` (300 trees, lr 0.1), `catboost` (300 iterations, lr 0.1, depth 6).
* BeyondArena "wins vs X" = number of the 35 tasks (Temporal excluded) on which the model beats X; p = two-sided sign test.
